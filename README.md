# 🎙️ 보이스 폴리셔 AI (Voice Polisher AI)

실시간 음성 인식(STT), 지능형 톤 보정, 실시간 다국어 번역을 지원하는 스마트 보이스 케어 웹 애플리케이션입니다.

## ✨ 주요 기능
- **실시간 음성 인식 (STT)**: 브라우저 내장 Web Speech API를 활용한 무지연 고정밀 음성 텍스트 변환
- **스마트 톤 보정 (Voice Polisher)**: 일상어, 비즈니스 이메일, 채팅, 보고서/공문 등 상황별 맞춤 톤 자동 정제
- **실시간 다국어 번역**: 한국어 음성을 영어, 일본어, 중국어, 스페인어 등 다양한 언어로 즉시 번역
- **음성 볼륨 비주얼라이저**: 마이크 입력에 반응하는 역동적인 음파 애니메이션
- **무설치 웹 지원**: 모바일(스마트폰), 태블릿, PC 웹 브라우저에서 즉시 실행 가능

## 🚀 기술 스택
- **프론트엔드**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **음성 기술**: Web Speech API, Web Audio API
- **번역 API**: MyMemory Translation API & 지능형 로컬 폴백 시스템
- **배포 플랫폼**: Vercel
